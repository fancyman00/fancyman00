## What I do

- Design modular backends with **Clean Architecture, DDD and bounded contexts**
- Build async APIs and ETL pipelines with **FastAPI, asyncio and PostgreSQL**
- Orchestrate reliable background workloads with **TaskIQ / Celery, Redis and Kafka**
- Connect services through **REST, gRPC and event-driven workflows**
- Ship and operate systems with **Docker, Linux, CI/CD and Nginx**
- Make production observable with **Prometheus, Grafana, Loki and Sentry**
- Integrate LLM workflows using **LangChain, LangGraph and MCP**
- Step into **React / Next.js / TypeScript** when a product needs a complete vertical slice

## A few things I've shipped

### 📊 [Sam-X](https://sam-x.ru) — Wildberries analytics SaaS

[![Sam-X website](https://img.shields.io/badge/Visit-sam--x.ru-7C3AED?style=flat-square&logo=googlechrome&logoColor=white)](https://sam-x.ru)

Leading backend development and architecture for a production multi-service platform.

- Designed **4 isolated services** with gRPC communication, retries, timeouts and circuit breakers
- Built idempotent ETL pipelines processing **50k+ transactions per day** with zero data loss
- Created a Redis-backed DAG task engine that reduced report generation from **30s to 3–5s**
- Introduced full observability and reduced incident detection time from hours to **~15 minutes**
- Set up GitHub Actions, Docker Compose deployments, SSL termination and production operations

### 🛰️ Space & embedded software

Contributed to a program of **four small spacecraft launched in July 2025**.

[![Launch confirmed](https://img.shields.io/badge/Launch_confirmed-25_July_2025-0B3D91?style=flat-square&logo=rocket&logoColor=white)](https://www.aerospacecapital.ru/ru/news12.html) **Mission report:** four AstroLine spacecraft were successfully deployed to orbit.

- Developed Python telemetry receivers for Raspberry Pi
- Ported and verified spacecraft attitude-control algorithms from C++ to Python
- Built an orbital differential-drag simulation engine for a 3U satellite constellation
- Worked with ADCS algorithms, AGI STK, serial protocols, CAN, I²C and embedded Linux
- Developed distributed voice communication software in C++ using UDP multicast and TCP
